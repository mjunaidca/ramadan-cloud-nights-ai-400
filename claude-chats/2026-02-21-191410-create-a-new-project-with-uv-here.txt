● Here's a breakdown of the choices:

  Multi-stage build — The builder stage has uv and all build tooling. The final
  image only gets the .venv and app code. Build tools, caches, and uv itself are
   discarded, shrinking the image significantly.

  python:3.12-slim — Based on Debian slim (~50MB vs ~350MB for the full image).
  Alpine would be smaller but causes issues with compiled Python packages due to
   musl vs glibc.

  --no-dev --frozen — Installs only production deps using the exact locked
  versions. No surprises in builds.

  Dependencies copied before code — pyproject.toml and uv.lock are copied first
  so dependency installation is cached. Code changes don't trigger a full
  reinstall.

  No uv in final image — Only the virtualenv is copied over. The final image has
   no package manager, reducing attack surface and size.

  Non-root would be the next step — For a real deployment you'd add a USER
  directive, but kept it out to stay simple as requested.

❯ can you guide how to runt his? 

● Sure! Here's how to run this locally using minikube (most common local K8s
  setup):

  1. Start minikube

  minikube start

  2. Build the image inside minikube's Docker

  Minikube has its own Docker daemon. You need to build the image there so K8s
  can find it:

  eval $(minikube docker-env)
  docker build -t live-code:latest .

  3. Set image pull policy

  Since it's a local image (not from a registry), update the deployment so K8s
  doesn't try to pull it remotely. Either add imagePullPolicy: Never to the
  container spec, or just apply it and patch:

  kubectl apply -f k8s.yaml
  kubectl set image deployment/live-code live-code=live-code:latest
  kubectl patch deployment live-code -p '{"spec":{"template":{"spec":{"container
  s":[{"name":"live-code","imagePullPolicy":"Never"}]}}}}'

  4. Check it's running

  kubectl get pods
  kubectl get svc live-code

  5. Access the app

  minikube service live-code

  This opens the NodePort service in your browser automatically. Or manually:

  curl $(minikube ip):30080/tasks

  Troubleshooting

  kubectl logs -l app=live-code      # check app logs
  kubectl describe pod -l app=live-code  # check pod events

❯ whats other docs urls than/ docs exposed by fastapi 

● FastAPI auto-generates these doc endpoints:

  - /docs — Swagger UI (interactive)
  - /redoc — ReDoc (read-only, cleaner layout)
  - /openapi.json — Raw OpenAPI schema (JSON)

  All enabled by default. You can disable any of them when creating the app:

  app = FastAPI(docs_url=None, redoc_url=None, openapi_url=None)
